# Applied Machine Learning and Deep Learning

This repository presents selected implementations in machine learning, deep learning, biomedical data analysis, computer vision, and signal processing. The projects demonstrate the application of classification, regression, clustering, neural networks, and data-preprocessing techniques across different datasets.

## Repository Structure

### Biomedical AI

Projects involving healthcare data and physiological signals:

- EEG signal processing and classification
- Heart disease classification using Logistic Regression, K-Nearest Neighbors, and Support Vector Machine
- Heart disease prediction using Logistic Regression
- Breast cancer classification using neural networks
- Diabetes classification using Support Vector Machine
- Parkinson’s disease classification using Support Vector Machine

### Computer Vision

Deep-learning projects involving image classification and recognition:

- Object recognition using convolutional neural networks
- Cats-versus-dogs image classification
- Face-mask detection using convolutional neural networks

### General Machine Learning

Projects demonstrating general supervised and unsupervised learning methods:

- Bike-sharing demand regression
- Seeds dataset clustering
- Spam email classification using Logistic Regression

## Methods Demonstrated

- Data preprocessing and exploratory analysis
- Classification and regression
- Supervised and unsupervised learning
- Logistic Regression
- K-Nearest Neighbors
- Support Vector Machines
- Neural networks and convolutional neural networks
- Model training and performance evaluation

## Technologies

- Python
- Jupyter Notebook
- NumPy

- Matplotlib
- Scikit-learn
- TensorFlow
- Keras

## Repository Purpose

This repository documents selected foundational and applied projects completed while developing my technical background in machine learning, deep learning, biomedical AI, and physiological signal analysis.
